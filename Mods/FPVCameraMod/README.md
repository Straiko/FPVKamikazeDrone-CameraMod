# FPV Kamikaze Drone - Flight Mode Mod (Acro <-> Non-Acro / Angle Mode)

Мод для игры **FPV Kamikaze Drone**, добавляющий переключение полетного режима между:
1. **ACRO MODE (Ручной / Rate):** Стандартный боевой режим без автовыравнивания — полное ручное управление вектором и угловой скоростью дрона.
2. **NON-ACRO MODE (Angle / Стабилизация горизонта):** Режим со стабилизацией — дрон автоматически выравнивается в горизонтальное положение при нейтральных стиках/клавишах, не переворачивается и устойчиво держит горизонт.

---

## 🎮 Управление в игре

| Действие | Клавиша | Описание |
|---|---|---|
| **Переключить режим** | **`V`** или **`C`** | Переключение между **Acro** (ручной) и **Non-Acro** (стабилизация) |

При каждом переключении на экране выводится статус:
- `[FLIGHT MODE] >> NON-ACRO << (Angle / Stabilized Horizon)`
- `[FLIGHT MODE] >> ACRO << (Full Manual / Rate Mode)`

---

## ⚙️ Настройка параметров

Параметры можно настроить в файле:
`.../FPVKamikazeDrone/FPVKamikazeDrone/Binaries/Win64/ue4ss/Mods/FPVCameraMod/Scripts/config.lua`

- `Config.ToggleKey = Key.V` — основная клавиша переключения режима.
- `Config.AltToggleKey = Key.C` — альтернативная клавиша переключения.
- `Config.DefaultMode = "ACRO"` — начальный режим при спавне (`"ACRO"` или `"NON_ACRO"`).
- `Config.StabilizerStrength = 4.5` — сила возврата в горизонт (чем выше, тем быстрее дрон восстанавливает горизонтальное положение).
- `Config.Damping = 0.35` — коэффициент демпфирования (плавность стабилизации без раскачки).
- `Config.MaxTiltAngle = 50.0` — максимальный угол наклона в стабилизированном режиме.
- `Config.ShowOnScreenMessage = true` — показ сообщений при переключении.

---

## 🚀 Запуск игры

В параметрах запуска Steam (Свойства -> Общие -> Параметры запуска):
```bash
WINEDLLOVERRIDES="dwmapi=n,b" %command% -dx11
```
*(Параметр `-dx11` переключает на DirectX 11 / DXVK, предотвращая GPU-краши на видеокартах GTX 1050 Ti).*
