# FPV Kamikaze Drone - Camera Switcher Mod (Macro <-> Non-Macro)

Мод для игры **FPV Kamikaze Drone**, добавляющий возможность переключения угла обзора камеры дрона-камикадзе между стандартным узким режимом (**Макро / Зум**) и широким углом обзора (**Не-макро / Wide FPV**).

---

## 🎮 Управление

| Действие | Клавиша | Описание |
|---|---|---|
| **Переключить режим** | **`V`** или **`C`** | Переключение между **Макро** (65°) и **Не-макро** (115°) |
| **Увеличить FOV** | **`]`** | Плавное расширение угла обзора (+5°) |
| **Уменьшить FOV** | **`[`** | Плавное сужение угла обзора (-5°) |

При каждом переключении в левом углу / чате выводится статус-уведомление с текущим режимом и градусом FOV.

---

## ⚙️ Настройка параметров

Все настройки можно изменить в файле:
`.../FPVKamikazeDrone/FPVKamikazeDrone/Binaries/Win64/ue4ss/Mods/FPVCameraMod/Scripts/config.lua`

Параметры:
- `Config.MacroFOV = 65.0` — угол обзора для режима Макро (зум / атака).
- `Config.NonMacroFOV = 115.0` — угол обзора для режима Не-макро (широкий обзор для маневрирования).
- `Config.SmoothTransition = true` — плавный переход между режимами (если `false` — переключается мгновенно).
- `Config.TransitionSpeed = 12.0` — скорость плавного перехода.

---

## 🚀 Как запустить игру

1. Запустите игру через Steam как обычно.
2. Модификация автоматически активируется через загрузчик UE4SS (`dwmapi.dll`).
3. В одиночной игре или тренировочном режиме взлетите на дроне-камикадзе и нажмите клавишу **`V`** (или **`C`**), чтобы переключить камеру с макро на широкий обзор.

> [!NOTE]
> Если в вашей версии Proton DLL-оверрайд не подхватился автоматически из реестра префикса, добавьте в **Параметры запуска** игры в Steam (Свойства игры -> вкладка «Общие»):
> ```bash
> WINEDLLOVERRIDES="dwmapi=n,b" %command%
> ```
