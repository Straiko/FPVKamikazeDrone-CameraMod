# FPV Kamikaze Drone - Visual Noise & Camera Mod (Acro <-> Non-Acro)

Мод для игры **FPV Kamikaze Drone**, добавляющий переключение между режимами картинки:
1. **АКРО (Картинка рябит):** Стандартный аналоговый FPV видеоканал с помехами, рябью, полосами помех VTX и эффектами CRT/VCR.
2. **НЕ-АКРО (Обычная чистая картинка без помех):** Чистый цифровой вид камеры без шумов, ряби, полос и помех.

---

## 🎮 Управление в игре

| Действие | Клавиша | Описание |
|---|---|---|
| **Переключить режим** | **`V`** или **`C`** | Переключение между **Акро** (рябь и помехи) и **Не-акро** (чистая картинка) |

При переключении на экране выводится статус:
- `[РЕЖИМ] >> НЕ-АКРО << (Чистая картинка без помех и ряби)`
- `[РЕЖИМ] >> АКРО << (Аналоговый FPV / Рябь и помехи ВКЛ)`

---

## ⚙️ Настройка параметров

Настройки находятся в файле:
`.../FPVKamikazeDrone/FPVKamikazeDrone/Binaries/Win64/ue4ss/Mods/FPVCameraMod/Scripts/config.lua`

- `Config.ToggleKey = Key.V` — основная клавиша переключения.
- `Config.AltToggleKey = Key.C` — альтернативная клавиша переключения.
- `Config.DefaultMode = "ACRO"` — начальный режим при спавне (`"ACRO"` — с помехами, `"NON_ACRO"` — чистая картинка сразу).
- `Config.AlsoStabilizeFlight = false` — опциональная помощь выравнивания горизонта в режиме Не-акро.
- `Config.ShowOnScreenMessage = true` — показ сообщений при переключении.

---

## 🚀 Запуск игры

В параметрах запуска Steam (Свойства -> Общие -> Параметры запуска):
```bash
WINEDLLOVERRIDES="dwmapi=n,b" %command% -dx11
```
*(Параметр `-dx11` переключает рендер на DirectX 11 / DXVK, предотвращая GPU-краши на видеокартах GTX 1050 Ti).*
